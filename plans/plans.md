📋 Mit láttam az eredeti app-ban, amit még nincs a Flutter kliensben:
1. 🎨 Vizuális Fejlesztések:
✅ Blurred background cover: A borító háttérben elmosódva
✅ Progress bar a borítón: Sárga/zöld sáv a borító alján
✅ Fullscreen cover modal: Nagy borító megtekintése
✅ Dynamic background colors: A borító színei alapján változik a háttér
2. 📊 Részletes Táblázatok:
✅ Chapters Table: Fejezetek listája időbélyegekkel és play gombokkal
✅ Audio Tracks Table: Hangfájlok listája fájlnévvel és időtartammal
✅ E-Book Files Table: E-könyv fájlok listája olvasás gombokkal
✅ Library Files Table: Összes fájl a könyvhöz (metadata, képek, stb.)
3. 🎛️ Fejlett Műveletek (More Menu):
✅ History: Lejátszási előzmények megtekintése
✅ Mark as Finished: Kézzel befejezettnek jelölni
✅ Discard Progress: Előrehaladás törlése
✅ Add to Playlist: Lejátszási listához adás
✅ Send E-book to Device: E-olvasóra küldés
✅ Manage Local Files: Helyi fájlok kezelése
✅ Delete Local Item: Helyi törlés
✅ Go to Web Client: Webes kliens megnyitása
✅ More Info: Részletes információk modal
4. 🎵 Fejlett Audio Player:
✅ Bookmarks: Könyvjelzők kezelése
✅ Playback Speed: Lejátszási sebesség változtatása
✅ Sleep Timer: Alvás időzítő
✅ Chapters Button: Fejezetek gomb a player-ben
✅ Casting Support: Casting támogatás
5. 📱 Interaktív Elemek:
✅ Expandable Sections: Összecsukható/kioldható szakaszok
✅ Clickable Timestamps: Kattintható időbélyegek a fejezetekben
✅ File Management: Fájlok kezelése és törlése
✅ RSS Feed: Podcast RSS feed kezelése
6. 🔧 Technikai Funkciók:
✅ Local vs Server: Helyi és szerver fájlok kezelése
✅ Download Management: Letöltések kezelése
✅ File System Integration: Fájlrendszer integráció
✅ Device Management: E-olvasó eszközök kezelése
